## 目标

对「职业历程」板块做两项体验升级：

1) **经历详情的呈现方式调整**：Web 端悬浮时卡片内部左右滑出详情；手机端点击手风琴展开详情。  
2) **背景动效替换**：用 Flow Field（风场）粒子流线动效替换当前“直线流星”，实现跟随鼠标/手指、可转弯并有闪动交互感；动效强度选择 **B（适中）**。

---

## 范围（In Scope）

### A. 职业历程详情交互

#### Web 端（桌面）
- 单条经历卡片采用 **“卡片内左右滑”** 的方式展示详情（不推动整块时间轴）。
- **默认态（B）**：仅展示
  - 公司 / 岗位 / 时间
  - 一行标签（subline）
- **悬浮态**：鼠标悬浮卡片时，卡片内部从左/右滑出「详情面」
  - 技术关键（techStack）
  - 要点列表（highlights）
- 离开悬浮区域，自动恢复默认态。

可访问性：
- 键盘 Tab 聚焦到卡片也应触发详情显示（`focus-within` / `onFocus`），避免仅鼠标可用。

#### 手机端（移动端）
- 采用 **手风琴**：一次只展开一个经历。
- 默认态同 Web：公司/岗位/时间 + subline。
- 点击卡片（或右侧展开按钮）后在卡片下方展开详情（techStack + highlights）。
- 点击其他经历：自动收起前一个。

---

### B. 背景动效：Flow Field（适中强度）

#### 视觉效果
- 背景存在大量微弱发光粒子/短线段，沿“风场”自然弯曲流动。
- 鼠标/手指移动会扰动风场，在指针附近增强粒子密度/亮度，形成“跟手、转弯、闪动”的交互感。
- 仅作用于「职业历程」板块（不影响全站）。

#### 性能与降级
- `prefers-reduced-motion: reduce`：完全关闭动效（保留静态星空背景）。
- 使用 IntersectionObserver：仅当职业历程进入视口才运行动画循环。
- 设备分级：
  - 桌面端：粒子数量略多
  - 移动端：粒子数量更少，但支持触摸/滑动触发扰动（仍保持“适中”强度，不追求满屏高亮）

## 方案概述

### 1) 职业历程卡片结构（概念）
- 卡片内部：`Summary 面` + `Detail 面` 两层
- 默认态显示 Summary（公司/岗位/时间 + subline）
- Hover/Focus 时触发 transform translateX，Detail 滑入；可用 CSS transition 完成
- 移动端使用 state 控制手风琴展开，不依赖 hover

### 2) Flow Field 实现（概念）
- Canvas 覆盖层：`position:absolute; inset:0; pointer-events:none;`
- 风场：
  - 在网格上生成二维向量（可由简易 noise/数学函数生成）
  - 随时间缓慢演化（低频变化）
- 粒子：
  - 位置按风场方向推进（advection）
  - 生命周期衰减（alpha/长度随时间淡出）
  - 超出范围回收复用（对象池/数组复用）
- 指针扰动：
  - pointer move 时，在指针半径范围内对风场向量叠加“旋涡/推拉”扰动
  - 同时短暂提高该区域粒子亮度/生成少量新粒子以增强交互感

## 验收标准

1) Web：悬浮某条经历卡片时，卡片内部左右滑出详情；离开后恢复默认态。
2) 移动端：点击某条经历展开详情；点击其他经历自动收起前一个（手风琴）。
3) 默认态只显示公司/岗位/时间 + subline（不显示 techStack/highlights）。
4) Flow Field 动效在职业历程内可见，且鼠标/手指移动时能明显跟随并出现转弯流动与闪动（强度适中）。
5) reduce motion 时无动效。
6) 不出现明显卡顿或严重耗电（移动端粒子数量有节制）。
